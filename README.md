# 우리장부

개인·부부용 가계부의 검토 가능한 첫 버전입니다. 거래, 예산, 고정비, 투자, 부채와 가정 합산 대시보드를 한 화면 흐름으로 구성했습니다.

## 실행

```bash
pnpm install
pnpm dev
```

배포용 확인은 `pnpm build`로 실행합니다.

## 문서와 설정

- `docs/PRD.md`: 제품 범위와 요구사항
- `docs/IMPORT_SPEC.md`: 하나카드·IBK기업은행 파일 규칙
- `db/schema.ts`: 사용자, 가정, 거래, 예산, 자산 데이터 구조
- `.env.example`: 외부 시세 서비스 환경 변수 예시

## 현재 구현 범위

- 반응형 가정 대시보드
- 직접 거래 입력
- 하나카드·IBK기업은행 `.xls/.xlsx/.csv` 브라우저 분석
- 기본 카테고리 추정
- 예산·고정비·투자·부채 화면
- 투자 시세 수동 갱신 흐름
- 가정 초대 코드 화면

배포된 검토 버전은 Sites의 비공개 접근을 사용합니다. PRD의 이메일·비밀번호 회원가입과 외부 시세 제공사 연결은 공개 운영 단계에서 보안 검토 후 활성화합니다.

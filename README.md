# 우리장부

개인·부부용 가계부의 검토 가능한 첫 버전입니다. 거래, 예산, 고정비, 투자, 부채와 가정 합산 대시보드를 한 화면 흐름으로 구성했습니다.

## 실행

```bash
pnpm install
pnpm dev
```

배포용 확인은 `pnpm build`로 실행합니다.

## 문서와 설정

- `docs/PRD.md`: 제품 범위와 요구사항
- `docs/IMPORT_SPEC.md`: 하나카드·IBK기업은행 파일 규칙
- `db/schema.ts`: 사용자, 가정, 거래, 예산, 자산 데이터 구조
- `.env.example`: 외부 시세 서비스와 Firebase 프로젝트 환경 변수 예시

## 현재 구현 범위

- 반응형 가정 대시보드
- 직접 거래 입력
- 하나카드·IBK기업은행 `.xls/.xlsx/.csv` 브라우저 분석
- 기본 카테고리 추정
- 예산·고정비·투자·부채 화면
- 금융위원회·한국거래소 공공데이터 기반 국내 주식·ETF 최근 종가 갱신
- Google 로그인과 사용자별 세션
- 7일간 유효한 가정 초대 링크·코드
- Cloudflare D1 기반 공동 장부 저장과 구성원 동기화

공공데이터포털에서 `금융위원회_주식시세정보` 활용 신청 후 발급받은 일반 인증키(Decoding)를 `.env.local`의 `PUBLIC_DATA_STOCK_API_KEY=` 뒤에 붙여 넣고 로컬 서버를 다시 실행하면 최근 종가 갱신을 사용할 수 있습니다. 인증키는 브라우저 코드나 GitHub에 올리지 않습니다.

화면에는 `출처: 금융위원회 「주식시세정보」(원천: 한국거래소)`와 공공누리 제4유형 조건을 표시합니다. 시세 원자료는 수정하지 않고, 평가금은 `최근 종가 × 보유수량`으로 별도 계산합니다.

## Google 로그인 설정

이 프로젝트는 로그인 없이 현재 브라우저의 개인 장부를 바로 사용할 수 있습니다. 가족과 공유하려면 설정 화면의 Google 로그인 옵션을 사용합니다. Firebase 프로젝트 `uri-jangbu`에 Google 제공자가 활성화되어 있어 별도의 OAuth 클라이언트 ID나 비밀번호를 만들 필요가 없습니다. 앱은 Firebase에서 받은 ID 토큰의 서명·발급자·프로젝트·만료 시간·이메일 인증 여부를 서버에서 검증합니다.

로컬 테스트는 기본값으로 바로 가능하며, 다른 Firebase 프로젝트로 옮길 때만 `.env.local`에 `FIREBASE_PROJECT_ID=`를 설정하고 Firebase Authentication의 승인된 도메인에 서비스 주소를 추가합니다.

로그인한 첫 사용자는 개인 가정을 자동으로 생성합니다. 설정 화면에서 7일간 유효한 초대 코드를 만든 뒤 상대방에게 전달할 수 있으며, 상대방은 자신의 Google 계정으로 로그인한 후 코드로 접속 권한을 요청합니다. 초대 링크를 열면 로그인만으로 요청할 수 있습니다. 장부 소유자가 요청자의 이름과 이메일을 확인해 승인하기 전에는 공동 장부 정보가 공개되지 않습니다. 초대 코드는 앱이 대신 이메일을 발송하지 않으며 사용자가 원하는 메신저·이메일로 직접 공유합니다.

배포 시에는 운영 도메인을 Firebase Authentication의 승인된 도메인에 추가하고, D1 마이그레이션을 운영 환경에 적용해야 합니다. 배포된 검토 버전은 Sites의 비공개 접근을 사용합니다.

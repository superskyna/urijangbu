# 거래 파일 가져오기 명세

## 공통

- 허용 형식: `.xls`, `.xlsx`, `.csv`
- 확장자보다 파일 내부 형식을 우선 판별한다.
- 파일은 사용자의 브라우저에서 읽고 원본을 서버에 보관하지 않는다.
- 파일명, 가져온 시각, 기관, 등록 건수, 확인 필요 건수만 저장한다.
- `sourceKey`가 같은 거래는 중복 등록하지 않는다.
- 잘못 가져온 경우 `importBatchId` 단위로 전체 취소할 수 있다.

## 하나카드

- 헤더 식별자: `이용일`, `승인번호`, `가맹점명`, `매입금액`, `상태`
- 지출액: `매입금액`
- 매입금액이 비어 있고 정상 승인인 경우 승인금액을 임시값으로 사용하고 확인 필요로 표시한다.
- `취소` 상태와 합계·문서 종료 행은 등록하지 않는다.
- 중복키: 카드 끝자리 + 승인번호 + 이용일 + 승인금액

## IBK기업은행

- 헤더 식별자: `거래일시`, `출금`, `입금`, `거래후 잔액`, `거래내용`, `거래구분`
- 상단의 현재잔액과 조회기준일을 계좌 잔액 정보로 사용할 수 있다.
- `체크` 출금은 일반 지출로 등록한다.
- `취소`와 `정정` 입금은 수입이 아니라 환불로 분류한다.
- 카드대금 납부와 알려진 본인 계좌이체는 소비에서 제외한다.
- `타행이체`와 `인터넷`은 실제 수입일 수도 있으므로 자동 제외하지 않고 확인 필요로 표시한다.

## 기본 분류

- 올리브영 → 쇼핑
- 이마트·홈플러스·롯데마트·코스트코·하나로마트 → 식비
- 병원·의원·한의원·약국 → 의료비
- 철도·대중교통·택시·하이패스 → 교통비
- 주유소 → 주유
- 정비소·세차장 → 차량관리
- 계비·동창회비·친목회비 → 계모임
- 사용자가 수정한 거래처 규칙을 최우선으로 적용한다.

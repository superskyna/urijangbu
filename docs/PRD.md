# 우리장부 PRD v0.3

## 제품 정의

개인이 자신의 거래와 자산을 관리하고, 부부가 각자의 가계부를 독립적으로 작성하면서 가정 전체 재무 상태를 합산해 보는 반응형 웹 가계부다. 향후 같은 공간·멤버 구조를 이용해 모임 가계부로 확장한다.

## 핵심 목표

1. 거래 파일을 넣으면 필요한 수입·지출을 자동 등록한다.
2. 개인 원본 기록을 유지하면서 부부 통합 대시보드를 제공한다.
3. 계좌·현금·카드·투자·부채를 합산해 순자산을 보여준다.
4. 예산, 저축 목표, 고정비를 월 단위로 관리한다.
5. PC에서는 파일과 설정, 모바일에서는 빠른 입력과 현황 확인에 집중한다.

## 사용자와 권한

- 이메일과 비밀번호로 가입하고 첫 로그인에서 각자의 닉네임을 정한다.
- 화면과 거래 작성자에는 남편·부인 같은 고정 호칭 대신 설정한 닉네임을 표시한다.
- 개인은 본인의 거래·계좌·자산을 등록하고 수정한다.
- 부부는 짧은 일회용 초대 코드로 가정 공간에 연결된다.
- 연결된 부부는 서로의 상세 거래를 조회할 수 있다.
- 원본 거래의 수정과 삭제는 작성자만 가능하다.
- 연결 해제 후에도 각자의 원본 기록은 보존한다.

## 주요 기능

### 대시보드

- 월 수입, 지출, 예상 저축, 예산 사용률
- 계좌·현금, 카드 미결제액, 투자자산, 부채, 순자산
- 개인 화면과 부부 합산 화면
- 최근 거래와 다가오는 고정비

### 거래

- 직접 입력과 엑셀·CSV 가져오기
- PC에서는 엑셀처럼 날짜·작성자·거래처·분류·계좌·구분·금액을 여러 행에 입력해 한 번에 저장
- 엑셀에서 복사한 여러 셀을 입력표의 어느 행·열에서든 붙여넣어 자동 배치
- 거래처·분류·계좌 통합 검색과 작성자·계좌별 필터, 필터 초기화
- 행마다 본인 또는 연결된 상대의 닉네임을 선택해 개인별 거래 원장을 유지
- 하나카드와 IBK기업은행 우선 지원
- 네이버페이·온누리상품권·지역화폐는 빠른 수기 입력
- 중복, 카드대금, 본인 계좌이체, 현금 인출 제외
- 환불은 수입이 아니라 기존 지출 차감
- 업로드 후 즉시 저장하고 사용자가 수정 가능
- 업로드 단위 전체 취소

### 소비 카테고리

식비, 관리비, 생활용품, 교통비, 주유, 차량관리, 의료비, 운동, 쇼핑, 통신·구독, 보험, 교육·육아, 여행·여가, 경조사·선물, 계모임, 세금·공과금, 금융수수료, 기타·미분류.

### 예산과 고정비

- 월 전체 및 카테고리별 예산
- 월 저축 목표와 달성률
- 월세·관리비·보험·통신·구독·계모임 등 반복비용
- 실제 거래와 고정비 예정 항목 연결
- 원금 상환은 소비에서 제외하고 이자만 지출로 반영

### 투자

- 국내·미국 주식과 ETF, 국내 펀드, 기타 자산
- 보유 수량과 평균 매입가 입력
- 사용자가 버튼을 누를 때만 시세와 원·달러 환율 갱신
- 평가금액, 평가손익, 수익률, 마지막 갱신 시각 표시
- 최대 20분 지연 시세 허용, 실제 주문 기능 제외

### 자산과 부채 입력

- 저축·예금: 자산명, 금융기관, 현재 잔액
- 국내·미국 주식과 ETF: 종목명·티커, 시장, 투자금, 보유 수량, 평균 매입가
- 대출: 대출명, 금융기관, 남은 원금, 금리
- 자산과 부채는 개인별로 등록하고 가정 대시보드에서 합산
- 계좌 잔액, 투자 평가액, 대출 원금을 반영해 순자산 계산

## 1차 버전 제외

- 은행·카드·증권사 자동 연결
- 소셜 로그인과 데이터 내보내기
- 개인 소비와 공동 소비 구분, 부부 간 정산
- 영수증 사진 인식과 주식 주문
- 다인 모임 가계부의 실제 운영 기능

## 보안과 품질

- 모바일과 PC에서 가로 스크롤 없이 사용한다.
- 금융기관 로그인 정보는 수집하지 않는다.
- 비밀번호는 단방향 해시로 저장하고 모든 통신을 암호화한다.
- 원본 업로드 파일은 보관하지 않는다.
- 시세 API 키는 서버에서만 관리한다.
- 중요 변경과 가져오기 이력을 기록한다.

## 성공 기준

- 신규 사용자가 10분 안에 첫 거래를 등록한다.
- 지원 파일의 정상 거래 90% 이상을 추출한다.
- 같은 파일 재업로드 시 중복 등록하지 않는다.
- 개인·가정 합산 금액이 일치한다.
- 모바일 첫 화면에서 순자산과 이번 달 현황을 확인한다.

## 후속 확장

- 모임 공간, 멤버 초대, 회비, 납부 현황, 공동 지출, 정산
- 금융기관 공식 API 연동 검토
- 시세 제공사 유료 실시간 상품 연결
